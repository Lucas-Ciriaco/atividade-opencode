# Mochila Zen

## Integrantes

- Lucas Ciriaco Borba

## Sobre o produto

Mochila fictícia que distribui o peso nas costas e toca uma trilha relaxante quando detecta que o estudante está atrasado. Público: estudantes universitários. Slogan: "Chegue atrasado, mas chegue em paz."

## Como rodar

```bash
npm install
npm run dev
```

## Arquitetura

Feature-Sliced Design: `app`, `pages`, `widgets`, `features`, `entities` e `shared`. Cada componente tem seu CSS Module.
